🛍️ E-Commerce Product Website

A modern and responsive E-Commerce Product Website designed to provide a clean, attractive, and user-friendly shopping experience. This project focuses on responsive UI design, product presentation, and a smooth browsing experience across different screen sizes.

✨ Features
🛍️ Modern product showcase
📱 Fully responsive design
🎨 Clean and attractive user interface
🖼️ Product images and detailed information
💰 Product pricing display
🧭 Simple and intuitive navigation
⚡ Fast and lightweight performance
💻 Optimized for desktop, tablet, and mobile devices

🛠️ Technologies Used
HTML5 — Website structure
CSS3 — Styling and responsive layout
JavaScript — Interactive functionality
